# AI-Enabled Bookstore
A collaborative project for Software Engineering at CCNY.

## About
In this project, we will develop an LLM-enabled smart bookstore with secure account management alongside a variety of features. Users will be able to purchase books, see recommendations based on their history, and have access to a reviewing system for each book.
